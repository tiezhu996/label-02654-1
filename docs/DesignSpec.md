# 设计规范 - 员工信息管理系统

> **版本**: v1.0  
> **创建日期**: 2026-02-13

---

## 1. 设计理念

- **简洁高效**: 企业级管理后台，注重信息展示效率
- **专业可靠**: 蓝色系主色调，传达专业、可信赖感
- **舒适体验**: 合理的间距、清晰的层次、流畅的交互

---

## 2. 色彩系统

### 主色 (Primary)
| 名称 | 色值 | 用途 |
|------|------|------|
| Primary | `#1677ff` | 主操作按钮、链接、选中态 |
| Primary Hover | `#4096ff` | 悬停状态 |
| Primary Active | `#0958d9` | 点击状态 |

### 功能色 (Functional)
| 名称 | 色值 | 用途 |
|------|------|------|
| Success | `#52c41a` | 成功、在职状态 |
| Warning | `#faad14` | 警告提示 |
| Error | `#ff4d4f` | 错误、离职状态、删除 |
| Info | `#1677ff` | 信息提示 |

### 中性色 (Neutral)
| 名称 | 色值 | 用途 |
|------|------|------|
| Title | `#000000e0` | 标题文字 |
| Text | `#000000a6` | 正文文字 |
| Secondary | `#00000073` | 辅助文字 |
| Border | `#d9d9d9` | 边框 |
| Background | `#f5f5f5` | 页面背景 |
| Container | `#ffffff` | 卡片/容器背景 |

## 4. 间距系统

基准单位: `4px`

| Token | 值 | 用途 |
|-------|-----|------|
| xs | 4px | 图标与文字间距 |
| sm | 8px | 紧凑元素间距 |
| md | 16px | 标准元素间距 |
| lg | 24px | 区块间距 |
| xl | 32px | 大区块间距 |

---

## 5. 组件规范

### 5.1 按钮 (Button)
- **主要按钮**: 蓝底白字，用于主操作
- **默认按钮**: 白底蓝字蓝边，用于次要操作
- **危险按钮**: 红底白字，用于删除等危险操作
- **圆角**: 6px
- **高度**: 32px (默认)

### 5.2 表格 (Table)
- **表头**: #fafafa 背景，加粗
- **行高**: 54px
- **斑马纹**: 奇数行 #fafafa
- **悬停**: #f5f5f5

### 5.3 卡片 (Card)
- **圆角**: 8px
- **阴影**: `0 1px 2px rgba(0,0,0,0.03), 0 2px 4px rgba(0,0,0,0.04)`
- **内边距**: 24px

### 5.4 表单 (Form)
- **标签位置**: 顶部
- **输入框高度**: 32px
- **圆角**: 6px

## 9. 响应式断点

| 断点 | 宽度 | 调整 |
|------|------|------|
| xs | < 576px | 侧边栏收起，单列布局 |
| sm | ≥ 576px | 侧边栏收起，双列布局 |
| md | ≥ 768px | 侧边栏展开 |
| lg | ≥ 992px | 标准布局 |
| xl | ≥ 1200px | 宽屏布局 |

---

## 10. 交互反馈

- **加载**: Spin 组件 + 骨架屏
- **成功**: Message 成功提示 (3秒自动消失)
- **错误**: Message 错误提示 (5秒自动消失)
- **确认**: Modal 二次确认 (删除操作)
- **表单校验**: 实时校验 + 提交校验
