## 1. 项目概述

构建一个基于 **FastAPI** 框架的员工信息管理网站，提供员工数据的增删改查（CRUD）功能，具备现代化的用户界面和容器化部署能力。

---

## 2. 核心功能需求

### 2.1 员工管理 (CRUD)

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **创建员工 (Create)** | 添加新员工信息，包含基础字段 | P0 |
| **查询员工 (Read)** | 列表展示、搜索、分页、详情查看 | P0 |
| **更新员工 (Update)** | 编辑员工信息 | P0 |
| **删除员工 (Delete)** | 删除员工记录（软删除/硬删除） | P0 |

### 2.2 员工信息字段

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 工号 (employee_id) | String | ✅ | 唯一标识，系统自动生成 |
| 姓名 (name) | String | ✅ | 员工姓名 |
| 性别 (gender) | Enum | ✅ | 男/女 |
| 年龄 (age) | Integer | ✅ | 年龄 |
| 部门 (department) | String | ✅ | 所属部门 |
| 职位 (position) | String | ✅ | 职位名称 |
| 邮箱 (email) | String | ✅ | 工作邮箱 |
| 电话 (phone) | String | ❌ | 联系电话 |
| 入职日期 (hire_date) | Date | ✅ | 入职日期 |
| 状态 (status) | Enum | ✅ | 在职/离职 |

### 2.3 用户认证与权限

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **用户登录** | 账号密码登录，JWT Token 认证 | P0 |
| **权限角色** | 管理员 (Admin) / 普通用户 (User) | P1 |
| **管理员** | 拥有全部 CRUD 权限 | P0 |
| **普通用户** | 仅查看权限，无编辑删除权限 | P1 |

### 2.4 辅助功能

- **搜索**: 按姓名、工号、部门搜索
- **分页**: 列表数据分页展示
- **排序**: 按入职日期、姓名排序
- **数据导出**: CSV 格式导出 ✅

### 2.5 报表与图表

| 图表类型 | 描述 | 优先级 |
|----------|------|--------|
| **部门人数统计** | 饼图/柱状图展示各部门人数分布 | P1 |
| **入职趋势图** | 折线图展示近12个月入职人数趋势 | P1 |
| **性别比例** | 饼图展示男女比例 | P2 |
| **在职/离职统计** | 展示员工状态分布 | P2 |
| **数据概览卡片** | 总人数、本月入职、在职率等关键指标 | P1 |

## 3. 技术架构

### 3.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **后端框架** | FastAPI | 高性能 Python Web 框架 |
| **认证** | JWT (python-jose) | Token 认证 |
| **ORM** | SQLAlchemy | 数据库对象关系映射 |
| **数据库** | PostgreSQL | 生产级关系型数据库 |
| **前端框架** | React 18 | 现代化前端框架 |
| **UI组件库** | Ant Design 5 | 企业级设计系统 |
| **图表库** | ECharts (echarts-for-react) | 数据可视化 |
| **HTTP客户端** | Axios | API 请求处理 |
| **容器化** | Docker + Docker Compose | 统一部署 |
